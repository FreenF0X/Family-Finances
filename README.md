# FamilyFinances

Сервис для ведения личного и семейного бюджета. 
Проект для демонстрации навыков проектирования микросервисной архитектуры, работы с высоконагруженными системами и event-driven подходом.

## Цель проекта

Построить систему, которая:
- Принимает транзакции (доходы/расходы) от пользователей;
- Хранит их в PostgreSQL (write-модель);
- Публикует события в Kafka;
- Строит аналитические отчёты в ClickHouse (read-модель);
- Покрыта мониторингом (Prometheus + Grafana) и unit-тестами.

## Архитектура (на словах)

Система состоит из трёх сервисов:

1. **Auth Service** — отвечает за аутентификацию. Принимает логин/пароль, выдаёт JWT.

2. **Budget Service** — write-модель. Принимает транзакции, пишет их в БД(PostgreSQL), публикует события в Kafka. Предоставляет CRUD API для транзакций и категорий.

3. **Analytics Service** — read-модель. Подписан на топик в Kafka, пишет данные в ClickHouse. Предоставляет gRPC-метод для получения агрегированных отчётов (например, сумма расходов по категориям за месяц).
